# Import / Export Job Orders

![Import / Export Job Orders screenshot](../assets/screenshots/import-export-job-orders.png)

This page lets you import or export multiple job orders at once, rather than entering them one by one. Warehouse and operations staff use this when they need to load job orders from external files or prepare batch data for another system.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-trucking-management-system#Report:Import_Export_Job_Orders1`

## How to Use

1. Select your preferred language using the language dropdown if needed.
2. Check the boxes next to the job order fields you want to include in your import or export (such as Job Date, Work Type, Route, or Container Count).
3. Use the search fields under each selected field to filter or match specific values if you're importing—for example, search for a specific route or work type.
4. For date ranges, enter the start date in the 'From' field and end date in the 'To' field if filtering by Job Date.
5. Click 'Import' to load job orders from a file, or 'Submit Request' to prepare your selected data for export.
6. Review the results and click 'Done' when finished, or 'Remove Changes' to clear your selections and start over.

## Tips

- Always check at least one field checkbox before importing or exporting, or the system will have nothing to process.
- If you're importing a large batch of job orders, use the date range filters (From/To) to split the import into smaller chunks—this reduces errors and makes troubleshooting easier.
