# Driver Trip Allowances Master Data Report

![Driver Trip Allowances Master Data Report screenshot](../assets/screenshots/driver-trip-allowances-master-data-report.png)

The Driver Trip Allowances Master Data Report shows the fee structure for drivers across different container types and trip scenarios. Operations staff and payroll managers use this page to view, update, and manage driver compensation rates, ensuring accurate payment for standard trips, reefer containers, double containers, and overnight assignments.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-trucking-management-system#Report:Driver_Trip_Allowances_Master_Data_Report`

## How to Use

1. Open the Driver Trip Allowances Master Data Report from the Master Data menu.
2. Review the table to see current fee amounts for each destination and container type.
3. To edit fees, select the checkboxes next to the rows you want to modify.
4. Click 'Bulk Edit' to change multiple fee amounts at once, or click a single row to edit individual entries.
5. Enter the new fee amounts in the required fields (Driver Fee, Assistant Fee, Overnight Fee).
6. Click 'Done' to save your changes, or 'Remove Changes' to discard edits.
7. Use 'Export' to download the fee schedule or 'Import' to upload bulk changes from a file.

## Tips

- Always export a backup of your current fee structure before making bulk changes, so you can restore it if needed.
- Use the checkboxes to select multiple destinations at once before bulk editing—this saves time when rates change across all locations.
- Remember that fees in this report directly affect driver payroll, so verify all changes are correct before submitting, especially for overnight and assistant fees.
