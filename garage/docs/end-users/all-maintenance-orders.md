# All Maintenance Orders

![All Maintenance Orders screenshot](../assets/screenshots/all-maintenance-orders.png)

The All Maintenance Orders page displays all vehicle maintenance records in your garage system. Operations staff use this page to track, review, and manage maintenance work across your fleet. Access this page to check maintenance status, schedule repairs, and monitor vehicle service history.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:All_Maintenance_Orders`

## How to Use

1. Open the Maintenance Management section and select 'All Maintenance Orders' to view the complete list of maintenance records.
2. Use the language dropdown at the top to change the interface language if needed.
3. Review the table columns to find the maintenance order you need—search by Maintenance ID, Vehicle name, or Maintenance Date.
4. Click the checkboxes next to individual orders to select them for bulk actions like Edit, Duplicate, or Delete.
5. Use the 'Bulk Edit' button to update multiple maintenance records at once, or click 'Print' to generate reports for your records.
6. Click 'Export' to download maintenance data to a file for external reporting or analysis.
7. Click 'Done' when you have finished your work and are ready to return to the main menu.

## Tips

- The multiple numbered checkboxes (4780709000...) represent individual maintenance records and vehicle data fields. Select these to choose which orders to work with when using bulk actions.
- Always review the 'Maintenance Status' column before scheduling new work—avoid duplicate repairs by checking if maintenance is already in progress or completed.
