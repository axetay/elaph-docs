# All Spare Parts

![All Spare Parts screenshot](../assets/screenshots/all-spare-parts.png)

The All Spare Parts page displays your complete inventory of garage maintenance parts with real-time stock levels, values, and compatibility information. Operations staff use this page to monitor stock status, identify low inventory items, and manage part records across your fleet maintenance operations.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:All_Spare_Parts`

## How to Use

1. Open the Spare Parts section and select 'All Spare Parts' to view your complete parts inventory
2. Use the language dropdown at the top if you need to change the display language for your region
3. Review the table columns to check current stock levels, minimum requirements, and stock status alerts
4. Select individual part checkboxes to perform bulk actions such as editing, duplicating, or deleting multiple parts at once
5. Click 'Bulk Edit' to update properties for selected parts, or 'Export' to save inventory data for reporting
6. Use 'Add' (or press Option + Shift + N) to create a new spare part record when you receive new inventory items

## Tips

- Always check the 'Stock Status' column before ordering—it shows whether parts are at minimum level or critically low to help prevent production delays
- Use 'Bulk Edit' when updating multiple parts with the same property (such as category or minimum stock level) rather than editing each part individually, which saves significant time
