# All Drivers

![All Drivers screenshot](../assets/screenshots/all-drivers.png)

The All Drivers page displays your complete driver roster and lets you manage driver records for your fleet. Operations staff use this page to view driver details, update licenses and contact information, and track driver documentation. Access this page when you need to verify driver eligibility, update records before maintenance scheduling, or manage driver information across your organization.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:All_Drivers`

## How to Use

1. Open the Fleet & Drivers section and select All Drivers to see the complete driver list.
2. Review the table columns to check driver names, national IDs, license expiry dates, and contact information.
3. Click the checkbox next to any driver row to select individual drivers, or use the Show as checkbox to select all drivers at once.
4. Use the Upload License Photo or Upload ID Photo columns to add or update driver documentation files.
5. To make changes to selected drivers, click Bulk Edit to update multiple records at once, or click a driver name to edit individual details.
6. Use the language dropdown (lang-select-dropdown) at the top if you need to view or enter information in a different language.
7. Click Export to save driver data to a file, or click Print to generate a driver report for records.

## Tips

- Before scheduling maintenance or assigning routes, always check the License Expiry Date column to ensure all drivers have valid licenses. Expired licenses mean the driver cannot operate vehicles.
- Use the Contact Number field to verify current phone numbers are stored correctly—you'll need accurate contact info if you need to reach drivers about schedule changes or maintenance updates.
