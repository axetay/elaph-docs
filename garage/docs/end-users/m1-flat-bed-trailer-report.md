# M1 Flat Bed Trailer Report

![M1 Flat Bed Trailer Report screenshot](../assets/screenshots/m1-flat-bed-trailer-report.png)

The M1 Flat Bed Trailer Report page lets you record and track maintenance activities for flat bed trailers in your fleet. Operations staff use this form to document inspections, repairs, and service work, then submit the completed report for record-keeping and compliance purposes.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:M1_Flat_Bed_Trailer_Report`

## How to Use

1. Select your preferred language from the Language dropdown at the top if needed.
2. Adjust the Volume range slider if you need to filter or specify maintenance volume details for this trailer.
3. For each maintenance item or inspection area, check the corresponding checkbox to flag that section as complete or applicable.
4. Use the text fields and dropdown menus to enter specific details about repairs, parts used, or inspection findings for each maintenance category.
5. Review all entries to ensure accuracy, then click 'Submit Request' to send the report for approval.
6. If you need to make changes before submitting, click 'Remove Changes' to clear entries and start over for that section.

## Tips

- Always check the relevant checkbox before entering details in that section—unchecked sections will not be included in your final report.
- Use the 'Add a Record' button if you need to document multiple maintenance items on the same trailer, rather than trying to fit everything into one set of fields.
