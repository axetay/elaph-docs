# All Fuel Controls

![All Fuel Controls screenshot](../assets/screenshots/all-fuel-controls.png)

The All Fuel Controls page lets you manage and monitor fuel consumption data across your vehicle fleet. Operations staff use this page to track fuel efficiency, set consumption benchmarks, and identify vehicles with unusual fuel usage patterns. Access this page regularly to maintain accurate fuel records and catch maintenance issues early.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:All_Fuel_Controls`

## How to Use

1. Select your language using the lang-select-dropdown at the top if needed.
2. Use the search field (s2id_autogen80_search) to find a specific vehicle by name or ID.
3. Review the table to see each vehicle's consumption data: Normal Consumption Rate, Total Liters, Average Consumption, Last Odometer, and Cost Per KM.
4. Check the checkboxes next to vehicles to select multiple records for bulk actions like editing or deleting.
5. Click Bulk Edit to update consumption rates or other settings for selected vehicles at once.
6. Use Export to download fuel data for reports, or Import to add new vehicle fuel records in bulk.
7. Click Done when finished, or navigate back using Main Forms or other menu buttons.

## Tips

- If Average Consumption is significantly higher than Normal Consumption Rate, the vehicle may need maintenance—check the Maintenance Sub Forms to schedule a service.
- Always export your fuel data before making bulk changes; this creates a backup in case you need to undo modifications.
