# M3 Reefer Trailer Report

![M3 Reefer Trailer Report screenshot](../assets/screenshots/m3-reefer-trailer-report.png)

The M3 Reefer Trailer Report page allows you to record and manage maintenance details for refrigerated trailers in your fleet. Use this page when performing scheduled maintenance or documenting repairs to track the condition and service history of each reefer unit. Fleet managers and maintenance staff access this form to ensure temperature-controlled trailers stay operational and compliant.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:M3_Reefer_Trailer_Report`

## How to Use

1. Select your preferred language from the language dropdown at the top if needed
2. Check the checkbox next to each maintenance item or repair you are documenting (such as compressor service, door seal inspection, or temperature control calibration)
3. For each checked item, enter the maintenance details in the associated text field and use the search dropdown to select the relevant service category or component
4. Use the volume range field if recording coolant levels, cargo capacity, or other measurable parameters for this trailer
5. Review all entered information for accuracy, then click Submit Request to save the maintenance record
6. Click Done to close the form, or use Main Forms to navigate back to the main menu
