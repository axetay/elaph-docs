# All Repair Details

![All Repair Details screenshot](../assets/screenshots/all-repair-details.png)

The All Repair Details page displays a complete record of all vehicle repairs performed across your garage locations. Operations staff use this page to review repair history, track mechanic performance, monitor costs, and manage repair records for compliance and invoicing purposes.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:All_Repair_Details`

## How to Use

1. Open the Maintenance Management section and select All Repair Details to view the complete repair log.
2. Use the Language dropdown at the top if you need to view the page in a different language.
3. Review the table columns to locate specific repairs by Repair Type, Problem Description, Mechanic Name, or Service Center Name.
4. Check boxes next to individual repair records to select them for bulk actions like editing, duplicating, or deleting.
5. Use the Print button to generate repair reports or the Export button to save repair data to a file for analysis.
6. Click Done when finished reviewing or making changes to return to the main maintenance menu.

## Tips

- Always verify the Invoice Amount matches your billing records before closing out repair records to avoid payment discrepancies.
- Use the Bulk Edit feature to update multiple repairs at once (for example, assigning a supervisor name to several repairs from the same date), rather than editing each repair individually.
