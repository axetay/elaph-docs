# Driver KPI Evaluation

![Driver KPI Evaluation screenshot](../assets/screenshots/driver-kpi-evaluation.png)

This page allows supervisors and managers to evaluate driver performance across four key areas: fuel efficiency, on-time delivery, safety incidents, and documentation compliance. Use this form monthly to record each driver's performance ratings and provide feedback. Completed evaluations help identify training needs and recognize top performers.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Form:Driver_KPI_Evaluation`

## How to Use

1. Select your preferred language from the dropdown at the top if needed.
2. Enter or select the driver name you are evaluating.
3. Enter or select the month and year being evaluated.
4. Enter or select your own name (the person conducting the evaluation).
5. For each performance category (Fuel Efficiency, On-Time Performance, Incidents, and Documentation), select the appropriate rating option that best matches the driver's performance.
6. In the comments field below each category, briefly explain the rating or note any specific examples.
7. Click Submit to save and send the evaluation.

## Tips

- Complete evaluations consistently each month on the same schedule so you don't miss any drivers or duplicate reviews.
- Use the comment fields to document specific incidents or examples—this helps drivers understand feedback and protects your company if performance issues need to be addressed later.
