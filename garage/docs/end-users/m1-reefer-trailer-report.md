# M1 Reefer Trailer Report

![M1 Reefer Trailer Report screenshot](../assets/screenshots/m1-reefer-trailer-report.png)

The M1 Reefer Trailer Report page lets you document maintenance activities and inspections for refrigerated trailers in your fleet. Maintenance staff and supervisors use this page to record what work was done, create maintenance records, and track equipment condition. Complete this form after performing maintenance or at scheduled inspection intervals.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:M1_Reefer_Trailer_Report`

## How to Use

1. Select your preferred language from the lang-select-dropdown at the top if needed.
2. Use the volume range field to record the refrigeration capacity or cooling performance measurement if applicable.
3. Check the relevant maintenance category checkboxes to indicate what type of work was performed (such as repairs, inspections, or component replacements).
4. For each maintenance item, use the search fields to find and select the specific equipment part or service area being worked on.
5. Enter any additional notes or observations in the text search fields to document condition issues or special findings.
6. Click Add a Record to save multiple maintenance entries for the same trailer if needed.
7. Click Submit Request or Done when your report is complete to finalize the maintenance record.

## Tips

- Always complete the checkboxes before entering part details—they help organize your maintenance records and make future lookups easier.
- Use the search fields to select parts from the master database rather than typing free text. This keeps your fleet records consistent and searchable.
