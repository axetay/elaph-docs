# Cost Per KM

![Cost Per KM screenshot](../assets/screenshots/cost-per-km.png)

The Cost Per KM page tracks fuel efficiency and expenses for your vehicle fleet. Operations staff use this page to monitor fuel consumption rates and calculate the actual cost of fuel per kilometer driven, helping you identify vehicles that need maintenance or are underperforming.

**URL:** `https://creatorapp.zoho.com/m.fahmy_ugologistics/u-go-garage-maintenance#Report:Cost_Per_KM1`

## How to Use

1. Open the Cost Per KM page from the Fuel Management section
2. Use the language dropdown at the top if you need to change the interface language
3. Review the table columns showing Total Liters, Average Consumption, and Cost Per KM for each vehicle
4. Select the checkboxes next to vehicle records to compare multiple vehicles or perform bulk operations
5. Click Export to save the data to a file for reporting, or Print to generate a physical document
6. Use Bulk Edit to update cost information for multiple vehicles at once if needed
7. Click Done when you've finished your review
